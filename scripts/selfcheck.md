## 通用检查（Fragment + Grand Finale 必做）

- [ ] **C1 画面先行**：开头从一个视觉画面开始（非「很久以前」「有一个少年」）
- [ ] **C2 缺失驱动**：情感引擎基于「失去 / 即将失去」而非「获得」
- [ ] **C3 反差构图**：至少一处「宏大 × 微小」对照
- [ ] **C4 信物在场**：有具体物件承载情感
- [ ] **C5 软转折密度**（条件启用）：每 300 字 ≥ 1 个软转折词（哪怕 / 可是 / 不过 / 只是 / 却 / 罢了）
- [ ] **C6 不完整闭合**：结尾有「未完之感」
- [ ] **C7 无直接情绪词**（条件启用）：避免「开心 / 难过 / 悲伤」等直情词
- [ ] **C8 无说教**：无任何形式的价值观输出

---

## Fragment 专项

- [ ] **CF1 字数**：200~800 字
- [ ] **CF2 时间折叠**（条件启用）：以「那时候他还不知道 / 多年以后」起笔
- [ ] **CF3 对话极短**（条件启用）：每句 ≤ 15 字、≤ 3 句、不说核心情感
- [ ] **CF4 戛然而止**：结尾是动作 / 画面，而非总结升华

---

## Grand Finale 专项

- [ ] **CG1 三重施压**（条件启用）：≥ 3 重绝境 + 呼吸孔（平凡间隙）
- [ ] **CG2 呼吸孔**：施压之间有平凡 / 温馨的间隙
- [ ] **CG3 一次性爆发**（条件启用）：最后 20% 集中释放，不分段
- [ ] **CG4 代价不可逆**：主角付出无法挽回的代价
- [ ] **CG5 flag 回收**：前文埋下的 flag / 伏笔后半段回收
- [ ] **CG6 字数**：2000~10000 字
